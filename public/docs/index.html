Overview & Concept

Sounify Pi bridges public Spotify metadata with your personal music streaming server (such as Navidrome or Airsonic) running on self-hosted hardware like an Orange Pi 3B / 5 or Raspberry Pi.

Traditional music downloaders either require Spotify Premium tokens, Spotify Developer accounts (which are frequently rate-limited or revoked), or heavyweight browser automation daemons. Sounify Pi eliminates all of that by taking a clean, lightweight approach:

Zero API Keys & Keyless Metadata Enrichment

It parses public Spotify embed pages (open.spotify.com/embed) to extract tracklists and artwork, enriches missing Release Year and Genre using the free iTunes Search API, pulls official high-fidelity audio matches from YouTube Music via yt-dlp, embeds ID3v2.3 tags, and immediately prompts Navidrome to scan the newly downloaded album.

Getting Started How It Works

How Sounify Pi Works Under the Hood

Unlike traditional music downloaders that demand Spotify Premium credentials, browser emulators, or fragile developer tokens, Sounify Pi operates on a completely decoupled architecture. It treats Spotify solely as a rich public metadata catalog and sources high-fidelity audio streams from YouTube Music.

The Core Architecture Insight

Spotify encrypts actual audio tracks with Widevine DRM and restricts developer APIs behind rate limits and logins. However, Spotify publishes full track names, ISRC codes, artist rosters, album names, track durations, and high-resolution cover artwork freely across its public web embed system. Sounify Pi captures this pristine metadata and uses it to find the identical studio audio master on YouTube Music.

Technical Execution Flow

1 Public Embed Scraping (No API Key)
src/Scraper/SpotifyScraper.php

Server-Side DOM & JSON State Extraction

When you input a Spotify URL (track, album, or playlist), Sounify Pi requests the lightweight public embed endpoint (https://open.spotify.com/embed/...) with optimized HTTP headers.

It parses the embedded hydration payload (<script id="__NEXT_DATA__">) or regex-matches the track state tree. This extracts clean track titles, artist names, album titles, duration in milliseconds, and the highest resolution artwork URL (typically 640×640 or uncompressed CDN assets) in under 200ms without sending a single API request to Spotify's gated endpoints.

Zero Spotify credentials needed
Supports Tracks, Albums & Playlists
Under 250ms parse time
2 Metadata Enrichment
src/Metadata/MetadataEnricher.php

Year, Genre & Disc Tag Completion

Spotify embed payloads often omit the release year and primary musical genre. Sounify Pi automatically queries the public Apple iTunes Search API (which requires no authorization keys).

It matches the artist and track title against verified Apple Music catalogue records, injecting exact release years, primary genres (e.g. Indie Rock, Synthwave, Classical), track index, and disc numbers into the download payload.

Accurate Year & Genre tagging
Free keyless iTunes Search API
Fallback defaults if offline
3 Intelligent Audio Match & Acquisition
src/Downloader/AudioDownloader.php + yt-dlp

Heuristic Search & Studio Audio Stream Selection

With verified metadata in hand, Sounify Pi builds a targeted query: ytsearch1:"Artist - Title (Official Audio)". Sounify Pi leverages the latest release of yt-dlp to locate the highest quality audio stream directly from YouTube Music or official artist topic channels.

The heuristic scoring prioritizes official studio tracks, filters out live performances, video intros, sketches, and 10-hour loops, and selects the pristine OPUS (251) or AAC (140) source stream before feeding it into FFmpeg.

Prefers Official Audio & Topic streams
Avoids music video dialogue & silence
ARM64 and Windows native binary support
4 Audiophile Transcoding & Tag Injection
FFmpeg + ID3v2.3 / Vorbis Tags

Flawless Tagging & Single Cover.jpg Standard

ffmpeg converts the raw audio stream to your requested output format (MP3 CBR 320k, FLAC Lossless 16/24-bit, M4A AAC, or OPUS).

Simultaneously, Sounify Pi injects standard ID3v2.3 metadata into MP3s or native Vorbis comments into FLAC/OPUS files. It writes the embedded cover image into the file headers and exports a clean cover.jpg alongside the tracks, complying with the universal Single Cover.jpg Standard expected by Navidrome, Plex, Jellyfin, and file managers.

MP3 320k, FLAC, M4A & OPUS
ID3v2.3 & Vorbis universal tags
Standardized Single cover.jpg
5 Instant Navidrome Subsonic Auto-Sync
src/Navidrome/NavidromeClient.php

Real-time Library Availability Across All Devices

Rather than waiting for scheduled daily disk scans or manually navigating to Navidrome's admin panel, Sounify Pi automatically fires an authenticated Subsonic API call (/rest/startScan.view) as soon as the download finishes.

Navidrome immediately indexes the newly created album folder, rendering it playable on your phone (Symfonium, Substreamer, DSub, Tempo) and desktop streaming apps within seconds.

4-Step Audio Pipeline

Every download job moves through a clean, deterministic 4-phase sequence:

PHASE 01

1. Scrape & Enrich

Fetches metadata from public Spotify embeds and queries keyless databases for the track's release year and genre.

PHASE 02

2. High-Fi Audio Grab

Uses yt-dlp with ytsearch: to fetch the matching official audio track and transcode to MP3 320k or FLAC.

PHASE 03

3. ID3v2 & Single Cover

Embeds ID3v2.3 tags (Title, Artist, Album, Year, Genre, Track) and saves a single standard cover.jpg per album.

PHASE 04

4. Navidrome Trigger

Notifies your local Navidrome server via Subsonic API startScan.view to make tracks playable on all your devices immediately.

Updating

Updates are managed directly through your platform's app store or via a single command:

  • App Stores (CasaOS / Umbrel): Open the Sounify Pi card in your dashboard and click Update when a new release notification appears.
  • Docker Compose: Run docker compose pull && docker compose up -d.
  • Native Installation: Run git pull && sudo systemctl restart sounify-pi.

Your downloaded music files and settings in SQLite (sounify.db) are preserved automatically across all updates.

Custom configuration

Audio formats (MP3 320k, FLAC lossless, M4A, OPUS), custom download directories, and Navidrome synchronization can be configured through the web interface in the Settings tab, or by passing environment variables (e.g. PORT=8080, TZ=UTC) in your platform's container settings.

Quick Start (Docker Compose)

The fastest and cleanest deployment method for Orange Pi or home servers is using Docker Compose:

docker-compose.yml 
services:
  sounify-pi:
    image: php:8.2-apache
    container_name: sounify-pi
    restart: unless-stopped
    ports:
      - "8080:8080"
    volumes:
      - ./:/var/www/html
      - /music:/var/www/html/storage/downloads
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=America/Santo_Domingo

Launch the service in background mode:

terminal 
docker compose up -d

Orange Pi Native Setup

For minimal resource consumption on low-power ARM64 single board computers running Armbian or Debian, install the native binaries directly:

terminal 
# 1. Update packages and install dependencies
sudo apt update
sudo apt install -y php-cli php-sqlite3 php-curl ffmpeg python3-pip

# 2. Install the latest yt-dlp binary
sudo pip3 install -U yt-dlp

# 3. Test the built-in server
php -S 0.0.0.0:8080 -t public

Systemd Service Setup

Run Sounify Pi as an automatic, self-restarting background service on boot:

/etc/systemd/system/sounify-pi.service 
[Unit]
Description=Sounify Pi Service (Music Downloader & Navidrome Sync)
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/sounify-pi
ExecStart=/usr/bin/php -S 0.0.0.0:8080 -t /opt/sounify-pi/public /opt/sounify-pi/public/index.php
Restart=always
RestartSec=5
Environment=PORT=8080
Environment=PHP_CLI_SERVER_WORKERS=4

[Install]
WantedBy=multi-user.target

Enable and start the service:

terminal 
sudo systemctl daemon-reload
sudo systemctl enable --now sounify-pi.service
sudo systemctl status sounify-pi

Year, Genre & ID3v2.3 Tags

Sounify Pi embeds standardized ID3v2.3 tags directly into MP3 frames using FFmpeg, ensuring full compatibility with Windows Media Player, macOS Music, VLC, Android, and Navidrome:

  • Release Year: Written to date, year, and ID3 frame TYER.
  • Genre: Queried from keyless databases and written to genre and ID3 frame TCON.
  • Track Number: Written to track (e.g. 1/12).
  • Attached Picture: Embeds the album cover as an attached JPEG picture stream.

Clean cover.jpg Standard (Zero Duplicates)

Unlike other downloaders that create multiple duplicate images per track (e.g. folder.jpg, cover.jpg, track.jpg), Sounify Pi strictly follows the Navidrome Best Practice Standard:

Directory Structure 
storage/downloads/
└── 4AMTapes/
    └── Como Has Logrado/
        ├── cover.jpg               <-- Single clean high-res album art
        └── 4AMTapes - Como Has Logrado.mp3 (with embedded cover)

20-Second Audio Preview in Library

In the Library tab of the Sounify Pi app, each song row features a play button. Clicking it opens a floating player bar that streams the first 20 seconds of the song directly with a live timer and automatic stop.

Audio Formats & Bitrates

Choose from multiple high-fidelity audio formats in the Settings tab:

  • MP3 320 kbps (CBR): Maximum compatibility across legacy media players, car dashboards, and smart speakers.
  • MP3 256 / 192 kbps: Balanced file sizes for memory-constrained micro-SD storage.
  • FLAC (Lossless): Uncompressed bit-perfect audio for audiophile collections.
  • Opus / M4A: Modern high-efficiency audio codecs.

Navidrome Subsonic Integration

When enabled in Settings → Navidrome Sync, Sounify Pi communicates with Navidrome's Subsonic API:

Subsonic API Request 
GET {NAVIDROME_URL}/rest/startScan.view?u={USER}&t={TOKEN}&s={SALT}&v=1.16.1&c=sounify-pi&f=json

Whenever a track or album finishes downloading, Sounify Pi dispatches this call, prompting Navidrome to scan the album folder instantly so it appears in your mobile streaming apps right away.

REST API Reference

Sounify Pi exposes a clean JSON REST API for automation and integration:

Endpoint Method Description
/api/resolve POST Scrapes metadata and tracklist from Spotify URL.
/api/download POST Enqueues single track or full album download job.
/api/jobs GET Returns live progress and status of active and recent downloads.
/api/library GET Lists downloaded songs from disk and database.
/api/library/delete POST Permanently deletes a track from disk & database and triggers Navidrome rescan.
/api/stream?id=ID GET Streams audio preview with byte-range headers.
/api/history GET Returns completed and failed download records.
/api/settings GET/POST Reads or updates audio quality, naming scheme, and Navidrome config.
/api/navidrome/scan POST Manually triggers an instant Navidrome library scan.

Troubleshooting & Tips

Upgrading yt-dlp

YouTube frequently updates its stream formats. Keep yt-dlp up to date with:

terminal 
sudo yt-dlp -U

Storage Permissions

Ensure the user running Sounify Pi has write permissions on the download directory:

terminal 
sudo chown -R $USER:$USER storage/downloads/
sudo chmod -R 775 storage/downloads/

Sounify Pi Documentation

The lightweight, self-hosted music downloader and automated library synchronizer engineered for Orange Pi (ARM64) and Navidrome servers.

v1.2.0 Orange Pi & SBC Ready Zero API Keys Navidrome Subsonic Auto-Sync ID3v2.3 + Year & Genre

Overview & Concept

Sounify Pi bridges public Spotify metadata with your personal music streaming server (such as Navidrome or Airsonic) running on self-hosted hardware like an Orange Pi 3B / 5 or Raspberry Pi.

Traditional music downloaders either require Spotify Premium tokens, Spotify Developer accounts (which are frequently rate-limited or revoked), or heavyweight browser automation daemons. Sounify Pi eliminates all of that by taking a clean, lightweight approach:

Zero API Keys & Keyless Metadata Enrichment

It parses public Spotify embed pages (open.spotify.com/embed) to extract tracklists and artwork, enriches missing Release Year and Genre using the free iTunes Search API, pulls official high-fidelity audio matches from YouTube Music via yt-dlp, embeds ID3v2.3 tags, and immediately prompts Navidrome to scan the newly downloaded album.

4-Step Audio Pipeline

Every download job moves through a clean, deterministic 4-phase sequence:

PHASE 01

1. Scrape & Enrich

Fetches metadata from public Spotify embeds and queries keyless databases for the track's release year and genre.

PHASE 02

2. High-Fi Audio Grab

Uses yt-dlp with ytsearch: to fetch the matching official audio track and transcode to MP3 320k or FLAC.

PHASE 03

3. ID3v2 & Single Cover

Embeds ID3v2.3 tags (Title, Artist, Album, Year, Genre, Track) and saves a single standard cover.jpg per album.

PHASE 04

4. Navidrome Trigger

Notifies your local Navidrome server via Subsonic API startScan.view to make tracks playable on all your devices immediately.

Quick Start (Docker Compose)

The fastest and cleanest deployment method for Orange Pi or home servers is using Docker Compose:

docker-compose.yml 
services:
  sounify-pi:
    image: php:8.2-apache
    container_name: sounify-pi
    restart: unless-stopped
    ports:
      - "8080:8080"
    volumes:
      - ./:/var/www/html
      - /music:/var/www/html/storage/downloads
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=America/Santo_Domingo

Launch the service in background mode:

terminal 
docker compose up -d

Orange Pi Native Setup

For minimal resource consumption on low-power ARM64 single board computers running Armbian or Debian, install the native binaries directly:

terminal 
# 1. Update packages and install dependencies
sudo apt update
sudo apt install -y php-cli php-sqlite3 php-curl ffmpeg python3-pip

# 2. Install the latest yt-dlp binary
sudo pip3 install -U yt-dlp

# 3. Test the built-in server
php -S 0.0.0.0:8080 -t public

Systemd Service Setup

Run Sounify Pi as an automatic, self-restarting background service on boot:

/etc/systemd/system/sounify-pi.service 
[Unit]
Description=Sounify Pi Service (Music Downloader & Navidrome Sync)
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/sounify-pi
ExecStart=/usr/bin/php -S 0.0.0.0:8080 -t /opt/sounify-pi/public /opt/sounify-pi/public/index.php
Restart=always
RestartSec=5
Environment=PORT=8080
Environment=PHP_CLI_SERVER_WORKERS=4

[Install]
WantedBy=multi-user.target

Enable and start the service:

terminal 
sudo systemctl daemon-reload
sudo systemctl enable --now sounify-pi.service
sudo systemctl status sounify-pi

Customizable File Naming Schemes

Configure how downloaded audio files are named in Settings → File Naming Scheme. Illegal filesystem characters (/\:*?"<>|) are automatically sanitized.

Title - Artist Song Name - Artist.mp3 01. Song Name - Artist.mp3
Title Only Song Name.mp3 01. Song Name.mp3

Year, Genre & ID3v2.3 Tags

Sounify Pi embeds standardized ID3v2.3 tags directly into MP3 frames using FFmpeg, ensuring full compatibility with Windows Media Player, macOS Music, VLC, Android, and Navidrome:

  • Release Year: Written to date, year, and ID3 frame TYER.
  • Genre: Queried from keyless databases and written to genre and ID3 frame TCON.
  • Track Number: Written to track (e.g. 1/12).
  • Attached Picture: Embeds the album cover as an attached JPEG picture stream.

Clean cover.jpg Standard (Zero Duplicates)

Unlike other downloaders that create multiple duplicate images per track (e.g. folder.jpg, cover.jpg, track.jpg), Sounify Pi strictly follows the Navidrome Best Practice Standard:

Directory Structure 
storage/downloads/
└── 4AMTapes/
    └── Como Has Logrado/
        ├── cover.jpg               <-- Single clean high-res album art
        └── 4AMTapes - Como Has Logrado.mp3 (with embedded cover)

20-Second Audio Preview in Library

In the Library tab of the Sounify Pi app, each song row features a play button. Clicking it opens a floating player bar that streams the first 20 seconds of the song directly with a live timer and automatic stop.

Audio Formats & Bitrates

Choose from multiple high-fidelity audio formats in the Settings tab:

  • MP3 320 kbps (CBR): Maximum compatibility across legacy media players, car dashboards, and smart speakers.
  • MP3 256 / 192 kbps: Balanced file sizes for memory-constrained micro-SD storage.
  • FLAC (Lossless): Uncompressed bit-perfect audio for audiophile collections.
  • Opus / M4A: Modern high-efficiency audio codecs.

Navidrome Subsonic Integration

When enabled in Settings → Navidrome Sync, Sounify Pi communicates with Navidrome's Subsonic API:

Subsonic API Request 
GET {NAVIDROME_URL}/rest/startScan.view?u={USER}&t={TOKEN}&s={SALT}&v=1.16.1&c=sounify-pi&f=json

Whenever a track or album finishes downloading, Sounify Pi dispatches this call, prompting Navidrome to scan the album folder instantly so it appears in your mobile streaming apps right away.

REST API Reference

Sounify Pi exposes a clean JSON REST API for automation and integration:

Endpoint Method Description
/api/resolve POST Scrapes metadata and tracklist from Spotify URL.
/api/download POST Enqueues single track or full album download job.
/api/jobs GET Returns live progress and status of active and recent downloads.
/api/library GET Lists downloaded songs from disk and database.
/api/stream?id=ID GET Streams audio preview with byte-range headers.
/api/history GET Returns completed and failed download records.
/api/settings GET/POST Reads or updates audio quality, naming scheme, and Navidrome config.
/api/navidrome/scan POST Manually triggers an instant Navidrome library scan.

Troubleshooting & Tips

Upgrading yt-dlp

YouTube frequently updates its stream formats. Keep yt-dlp up to date with:

terminal 
sudo yt-dlp -U

Storage Permissions

Ensure the user running Sounify Pi has write permissions on the download directory:

terminal 
sudo chown -R $USER:$USER storage/downloads/
sudo chmod -R 775 storage/downloads/
